# Wave Radio (Android starter project)

A small native Android internet-radio app. It fetches public station listings from Radio Browser and streams the station URLs directly. It includes category buttons, station search, favourites for the current session, and play/pause.

## Build an APK
1. Install Android Studio (current stable) with Android SDK Platform 35.
2. Open this `WaveRadio` folder in Android Studio and allow Gradle sync.
3. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
4. Android Studio creates the debug APK under `app/build/outputs/apk/debug/app-debug.apk`.

Internet access is required. Radio Browser listings and individual station streams are provided by third parties; availability and rights vary by station and region. This starter app does not host music.
